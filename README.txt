Cyber Security Roadmap — iPhone Web App

هذه النسخة مبنية على نفس ملف Cyber_Roadmap_Mobile.html.
تم تغيير التصميم والألوان فقط، مع الحفاظ على الـRoadmap والمحتوى والروابط والمنطق.

للنشر على GitHub Pages:
1. ارفع index.html + manifest.webmanifest + sw.js + icon.svg إلى root في الـrepository.
2. فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root).
3. افتح رابط Pages من Safari على iPhone.
4. Share > Add to Home Screen.
